<h2 id="10-08-2026" data-text="October 8, 2026" tabindex="-1">October 8, 2026</h2>

<ul>
<li><strong>Gemini 3.7 Flash deprecation</strong>:
<a href="/gemini-api/docs/whats-new-gemini-3.7"><code translate="no" dir="ltr">gemini-3.7-flash</code></a> is deprecated
and has been replaced by <a href="/gemini-api/docs/latest-model"><code translate="no" dir="ltr">gemini-3.8-flash</code></a>.
All requests to <code translate="no" dir="ltr">gemini-3.7-flash</code> are automatically routed to
<code translate="no" dir="ltr">gemini-3.8-flash</code>. Update your model string to <code translate="no" dir="ltr">gemini-3.8-flash</code> and
review the <a href="/gemini-api/docs/latest-model">Gemini 3.8 Flash guide</a>.</li>
<li><strong>Gemini 3.5 Flash deprecation</strong>:
<a href="/gemini-api/docs/whats-new-gemini-3.5"><code translate="no" dir="ltr">gemini-3.5-flash</code></a> is deprecated
and has been replaced by <a href="/gemini-api/docs/whats-new-gemini-3.6"><code translate="no" dir="ltr">gemini-3.6-flash</code></a>.
All requests to <code translate="no" dir="ltr">gemini-3.5-flash</code> are automatically routed to
<code translate="no" dir="ltr">gemini-3.6-flash</code>. Update your model string to <code translate="no" dir="ltr">gemini-3.6-flash</code> (or
<a href="/gemini-api/docs/latest-model"><code translate="no" dir="ltr">gemini-3.8-flash</code></a>) and review the
<a href="/gemini-api/docs/whats-new-gemini-3.6">Gemini 3.6 Flash guide</a>.</li>
<li><p><strong>Deep Research Agent <code translate="no" dir="ltr">deep-research-pro-preview-12-2025</code> deprecation</strong>:
The <code translate="no" dir="ltr">deep-research-pro-preview-12-2025</code> agent is deprecated and will be
<a href="/gemini-api/docs/deprecations#managed-agents">shut down</a> on <strong>October 23,
2026</strong>.</p>

<p>Migrate your requests to one of the newer <a href="/gemini-api/docs/deep-research">Deep
Research</a> agent versions:</p>

<ul>
<li><a href="/gemini-api/docs/models/deep-research-preview-04-2026"><code translate="no" dir="ltr">deep-research-preview-04-2026</code></a>:
Designed for speed and efficiency, ideal to be streamed back to a client
UI.</li>
<li><a href="/gemini-api/docs/models/deep-research-max-preview-04-2026"><code translate="no" dir="ltr">deep-research-max-preview-04-2026</code></a>:
Maximum comprehensiveness for automated context gathering and synthesis.</li>
</ul>

<p>To migrate, update the <code translate="no" dir="ltr">agent</code> parameter in your <code translate="no" dir="ltr">interactions.create</code>
requests from <code translate="no" dir="ltr">deep-research-pro-preview-12-2025</code> to
<code translate="no" dir="ltr">deep-research-preview-04-2026</code> (or <code translate="no" dir="ltr">deep-research-max-preview-04-2026</code>).</p></li>
</ul>

<li><p>Released <code translate="no" dir="ltr">gemini-2.0-flash-live-001</code>, a public preview version of the
<a href="/gemini-api/docs/live">Live API</a> model with billing enabled.</p>

<ul>
<li><p><strong>Enhanced Session Management and Reliability</strong></p>

<ul>
<li><strong>Session Resumption:</strong> Keep sessions alive across temporary network
disruptions. The API now supports server-side session state storage (for
up to 24 hours) and provides handles (session_resumption) to reconnect
and resume where you left off.</li>
<li><strong>Longer Sessions via Context Compression:</strong> Enable extended
interactions beyond previous time limits. Configure context window
compression with a sliding window mechanism to automatically manage
context length, preventing abrupt terminations due to context limits.</li>
<li><strong>Graceful Disconnect Notification:</strong> Receive a <code translate="no" dir="ltr">GoAway</code> server
message indicating when a connection is about to close, allowing for
graceful handling before termination.</li>
</ul></li>
<li><p><strong>More Control over Interaction Dynamics</strong></p></li>
<li><p><strong>Configurable Voice Activity Detection (VAD):</strong> Choose sensitivity
levels or disable automatic VAD entirely and use new client events
(<code translate="no" dir="ltr">activityStart</code>, <code translate="no" dir="ltr">activityEnd</code>) for manual turn control.</p></li>
<li><p><strong>Configurable Interruption Handling:</strong> Decide whether user input
should interrupt the model&#39;s response.</p></li>
<li><p><strong>Configurable Turn Coverage:</strong> Choose whether the API processes all
audio and video input continuously or only captures it when the end-user
is detected speaking.</p></li>
<li><p><strong>Configurable Media Resolution:</strong> Optimize for quality or token usage
by selecting the resolution for input media.</p></li>
<li><p><strong>Richer Output and Features</strong></p></li>
<li><p><strong>Expanded Voice &amp; Language Options:</strong> Choose from two new voices and
30 new languages for audio output. The output language is now
configurable within <code translate="no" dir="ltr">speechConfig</code>.</p></li>
<li><p><strong>Text Streaming:</strong> Receive text responses incrementally as they are
generated, enabling faster display to the user.</p></li>
<li><p><strong>Token Usage Reporting:</strong> Gain insights into usage with detailed
token counts provided in the <code translate="no" dir="ltr">usageMetadata</code> field of server messages,
broken down by modality and prompt or response phases.</p></li>
</ul></li>
</ul>
