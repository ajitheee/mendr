everything here is written and ready for you to send. i can't post from your accounts, so you're the one who hits send. the goal of the week is to get the first handful of real people to run mendr and tell you what they think.

one thing to line up first: the posts below assume `npx mendr fix-llm .` works, which means the npm package is published. do that (see ../PUBLISH.md once it exists, or `npm publish --access public` from the repo root after `npm login`). if you haven't published yet, the DMs still work as-is, because they offer to run mendr on the person's repo and send them the diff, which doesn't need them to install anything.

the real hook is the diff. for anyone who shows even mild interest, offer to run mendr on their repo and send them the exact patch. that lands better than any pitch.
