Privacy

Written against how Mendr actually works — not generic promises. The authoritative, code-level detail is in TRUST.md.

Where the scan runs

Mendr scans your repository inside your own GitHub Actions runner. The CLI reads your code, the bundled retirement registry, and your local git. The default audit makes no network calls at all — that is enforced in code (--offline, and a build-time test that runs the audit under a network-blocking preload), not just asserted here.

What leaves your environment

With the standalone CLI or the tracking-issue workflow: nothing leaves — the report is printed, or written to one GitHub issue in your own repository.

If you connect the Mendr GitHub App, your workflow sends it only the audit findings: model ids, file paths, line numbers, classifications, secret-redacted snippets of at most seven lines, and line hashes. Never your source code, never a clone, never a key. The upload is authenticated by the run's GitHub OIDC token, so there is no secret to store. The App holds checks: write and metadata: read only; it cannot read repository contents.

What the App stores

DataKept
Which account installed the App, and which repositories it covers (ids, names)while installed
Per audit run: commit, the findings (paths, line numbers, classifications, redacted snippets), and the result countssee retention below
A security audit log of events (installs, audits received, deletions) — counts and ids onlyfor incident response

Not stored, ever: your source code, your GitHub tokens (your sign-in token lives only in an encrypted browser cookie), installation tokens (minted in memory, never written down), or provider API keys (Mendr never receives one). The one sensitive stored field — the findings — is encrypted at rest with a key held outside the database.

How long, and how to delete it

  • Uninstall the App → every finding and repository record is deleted immediately; only a minimal deletion record remains.
  • Remove a repository from the installation → its findings are deleted.
  • Delete on demand → from a repository's page in the App, "Delete stored data" removes its findings at any time.
  • Retention → runs age out on a configurable schedule, and a per-repository cap always applies.

Who can see your findings

Only people GitHub confirms can access the repository. Signing in proves who you are; the App checks your GitHub access on every view. Findings for a repository are never shown to anyone GitHub does not already let into that repository.

Third parties

Mendr's hosted App talks only to the GitHub API (to write the check and confirm your access). There is no analytics, advertising, or third-party tracking on the App. Fonts on this marketing site load from Google Fonts.
