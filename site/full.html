The commands

A small set, run in your own environment.

mendr audit [path] · previewThe audit. Source, config and registry in one report with four honest conclusions. Needs only the repository.
mendr audit . --install · previewScaffolds a GitHub workflow that keeps one issue per repo current: new, continuing, resolved. contents: read, issues: write.
mendr fix-llm [path]Print the gated diff for a retired id at a verified call site—proved against your type-check and tests before it touches your code. Released, v0.1.0.
mendr watch [path]The lightweight tracker: which deprecated ids a repo uses, by deadline, in one self-updating issue. Released, v0.1.0.

Install

Run the audit. Thirty seconds, no key, nothing changed.

Point it at a repo. It scans TypeScript, TSX, Python and config, joins the retirement registry, and prints every retiring model with its location, deadline and migration evidence. Add --install to keep one GitHub issue current.
