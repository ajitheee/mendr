Questions

The things people search the day their app breaks.

Is gpt-4 being deprecated?
Yes. OpenAI retires gpt-4 (and gpt-4-0613) on October 23, 2026. Calls to it stop working after that date. The current replacement is gpt-4.1 / the latest GPT model.
When does gpt-3.5-turbo shut down?
gpt-3.5-turbo and gpt-3.5-turbo-0125 retire on October 23, 2026, in the same OpenAI wave as gpt-4. Move to a current small model such as gpt-4o-mini or the latest GPT.
What OpenAI models retire on October 23, 2026?
12 in one wave: gpt-3.5-turbo, gpt-3.5-turbo-0125, gpt-4, gpt-4-0613, gpt-4-1106-preview, gpt-4-turbo, gpt-4-turbo-2024-04-09, gpt-4.1-nano, gpt-4o-2024-05-13, gpt-image-1, o3-mini, o4-mini.
Was gemini-2.0-flash retired?
Yes. Google has retired gemini-2.0-flash. Use an alias like gemini-flash-latest or a current Gemini model so you are not pinned to a version that gets retired again.
How do I find deprecated model ids in my codebase?
Run Mendr on your repo. It scans the code, finds every retired or soon-to-retire model id, and tells you which are live call sites versus data references, before anything breaks in production. It runs read-only: npx github:ajitheee/mendr#v0.1.0 watch .
What happens when a provider retires a model id?
Calls to that model id start failing (typically a 404 or an invalid-model error). Your own code does not change, so it compiles fine and only breaks at runtime, usually in production. Tracking retirement dates ahead of time is the only way to migrate before that happens.
